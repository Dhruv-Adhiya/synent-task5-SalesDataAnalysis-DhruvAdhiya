# Superstore Sales Data Analysis

## Problem Statement

The objective of this project is to analyze the Superstore Sales dataset to understand overall business performance and identify meaningful business insights. The analysis focuses on revenue trends, top-selling products, category-wise sales performance, and regional sales distribution using Python data analysis and visualization libraries.

---

## Dataset Details

- **Dataset Name:** Superstore Sales Dataset
- **File Format:** CSV
- **Dataset Used:** `Superstore_Sales.csv`

### Features Included

- Order ID
- Order Date
- Ship Date
- Customer Information
- Product Category
- Product Name
- Region
- Sales

### Dataset Purpose

The dataset contains sales transaction records of a retail superstore business and is used to perform exploratory business analysis and identify sales patterns.

---

## Approach

The following steps were performed during the analysis:

### 1. Data Loading
- Imported the dataset using Pandas.

### 2. Data Cleaning
- Removed duplicate records.
- Cleaned column names.
- Converted `Order Date` into datetime format.
- Created a `Month_Year` column for trend analysis.

### 3. Exploratory Data Analysis

#### Monthly Revenue Trend Analysis
- Calculated monthly sales revenue.
- Visualized revenue growth over time using line charts.

#### Top-Selling Products Analysis
- Identified top 10 products based on total sales.
- Visualized product performance using bar charts.

#### Category Sales Analysis
- Analyzed total sales generated by each product category.
- Compared category performance using bar plots.

#### Sales Distribution Analysis
- Visualized overall sales distribution using scatter plots.

#### Regional Sales Analysis
- Compared sales performance across different regions.

### 4. Business Insights Generation
Generated important insights such as:
- Highest revenue month
- Best-selling product
- Highest sales category
- Lowest sales category
- Best performing region

### 5. Report Generation
- Saved generated insights into a text report file.
- Saved cleaned dataset for future analysis.

---

## Results

### Key Findings

- Identified monthly revenue growth patterns.
- Determined the top-selling products in the business.
- Found the highest and lowest performing sales categories.
- Identified the region generating maximum sales revenue.
- Successfully generated visual reports and business insights.
